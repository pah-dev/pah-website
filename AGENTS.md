# AGENTS.md

## Proyecto
Sitio web estático (HTML + CSS + JS vanilla). Sin build, sin dependencias, sin tests.

## Cómo abrir
Abrir `index.html` directamente en el navegador. No hay servidor ni comando de inicio.

## Identidad visual
Los colores se definen en `css/styles.css` bajo `:root` y deben coincidir con el logo SVG:
- `--primary: #082444` (azul marino, del logo)
- `--secondary: #337171` (teal, del logo)

## Notas
- El archivo del logo tiene espacios en el nombre (`01-logo-principal-azul - copia.svg`). Mantenerlo así o actualizar todas las referencias si se renombra.
- Fuentes cargadas desde Google Fonts (Inter) — requiere conexión.
